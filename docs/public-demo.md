# Публичное демо Sana Quest

Адрес: **https://occurring-exciting-done-leader.trycloudflare.com**.

Это временный демонстрационный экземпляр для проверки проекта другими участниками и жюри. Приложение и PostgreSQL запущены на компьютере команды, а Cloudflare Quick Tunnel предоставляет HTTPS-доступ из интернета. Постоянный облачный сервер не используется.

## Что доступно

- Те же девять тестовых аккаунтов, включая администратора; пароль `Pass1234!`.
- Регистрация, управление ролями и тарифами, конструктор задач, локальный помощник, каталог, отклики, версии, файлы и отзывы.
- Локальный видеорендер без голоса для Pro.
- Отдельная база и отдельное хранилище файлов. Рабочий экземпляр на localhost:8080 и его данные не публикуются.

Публичное демо не использует `.env` и личные API-ключи команды. OpenAI, распознавание аудио и серверная озвучка здесь отключены. Их реальная работа проверена отдельно и описана в `verification.md`. Загружайте в общий демонстрационный экземпляр только тестовые материалы.

Готовый пример видео: [«Карта доступного города», 30 секунд](https://occurring-exciting-done-leader.trycloudflare.com/media/d4f57d2b1127c534c8aa07ce013d1bde/final.mp4). Видео создано из согласованного сценария без внешних API; пробный ролик прошёл этап подтверждения, после чего выполнен финальный рендер.

## Запуск

Из корня репозитория:

```bash
docker compose -f compose.demo.yaml up --build -d
docker compose -f compose.demo.yaml logs --tail=60 tunnel
```

Cloudflare выдаст адрес вида `https://…trycloudflare.com`. Он выводится в журнале сервиса `tunnel`. Новый запуск туннеля может выдать другой адрес — в этом случае обновите ссылку в README и этом документе. Исходный адрес нельзя восстановить одной только конфигурацией Quick Tunnel.

Локальная проверка именно публичного экземпляра:

```bash
curl http://localhost:8084/api/health
docker compose -f compose.demo.yaml ps
```

Ожидается `{"status":"ok"}`. У базы публичного демо нет порта, опубликованного на хосте. Том данных и сеть принадлежат отдельному Compose-проекту `sana-public-demo`.

## Во время демонстрации

Оставьте Docker и компьютер включёнными и подключёнными к интернету. Не останавливайте сервис `tunnel`, если текущая ссылка уже передана жюри. Закрытие терминала не останавливает контейнеры, запущенные с `-d`. Ссылка зависит от работы этого компьютера и сервиса Cloudflare; постоянная доступность не гарантируется.

После окончания демонстрации:

```bash
docker compose -f compose.demo.yaml down
```

Команда сохраняет данные в volumes. Повторный запуск восстанавливает данные, но может изменить публичный адрес. Команда с `-v` удалит данные демонстрационного экземпляра.

Для размещения независимо от ноутбука потребуется внешний сервер с Docker и постоянным хранилищем. HTTPS-доступ к нему можно настроить через домен и обратный прокси либо именованный туннель. Сам по себе именованный туннель не переносит приложение в облако: сервер приложения и база должны продолжать работать. [Документация Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/).
