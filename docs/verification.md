# Проверка MVP

Дата: 23 сентября 2026. Среда проверки: macOS ARM64 + Docker Desktop; PostgreSQL и production image запускаются контейнерами.

## Выполненные проверки

- `go test -race ./server`: формула и снятие подтверждений, неизменяемость опубликованных версий, публикация короткой потребности с нулём, уведомления, ограничения ввода/URL, локальный AI contract, субтитры.
- TypeScript typecheck и production Vite build.
- `scripts/smoke.py`: 19 сквозных API-проверок на отдельной базе, включая чужое редактирование, устаревшую запись, видимость нулевой задачи, старый отклик, повторный отзыв, XP и план.
- Повторный API smoke в отдельном Docker Compose проекте, с чистой базой и **без .env / API-ключей**.
- Браузер: 0 → отклик → 100 → v2 → сравнение → выбор → подтверждённый этап → сдача → отзыв. Ошибок JavaScript в сценарии не обнаружено.
- RU / KK / EN и ширины 320, 390, 768, 1440 px. Проверка отсутствия горизонтальной прокрутки.
- Клавиатурный skip link и axe: каталог на RU/KK/EN, команды, тарифы, задача, редактор, мастерская. Итоговый прогон: 0 выявленных нарушений проверяемых автоматических правил. Автоматическая проверка не равна сертификации WCAG.
- Реальный OpenAI Responses: 3 уточняющих вопроса, неизвестный контакт оставлен пустым.
- Реальные TTS/STT с настроенным ElevenLabs: короткие примеры RU / KK / EN синтезированы и распознаны обратно. Текст совпадает по смыслу, возвращается на обязательную пользовательскую проверку.
- Docker video pipeline: отдельный pilot, подтверждение, полный MP4, H.264, 1280×720, 45 секунд. Кадр просмотрен. Сценарий индивидуален для опубликованной задачи; paid LLM для рендера не вызывается.

## Что проверять вручную перед защитой

- Реальный микрофон и выбранный браузер (доступ к устройству требует разрешения самого браузера).
- Качество произношения и распознавания конкретных RU/KK/EN записей; наличие языка в провайдере не гарантирует качество каждого акцента и записи.
- Прохождение со скринридером VoiceOver/NVDA реальным пользователем.
- Текущий баланс и доступность внешних API. В отсутствие API показать обозначенный локальный помощник.

## Ограничения

- Демонстрационные роли и подписка; настоящий платёж не проводится.
- Системный TTS зависит от установленных голосов. Произвольное аудио без API не распознаётся.
- Интерфейс локализован; тексты задач и отзывов остаются на языке автора. Автоматического скрытого перевода утверждённых фактов нет.
- Субтитры делятся по тексту; тайминг приблизительный, без forced alignment.
- MVP использует один JSONB-агрегат и один worker. Для масштаба нужна миграция на нормализованные таблицы и очередь с lease.
- Счётчик платных API-вызовов защищает текущий процесс демо и обнуляется при перезапуске; не является биллинговым ledger.
- Рейтинг означает подтверждённую заполненность, не гарантию достоверности бизнеса и не оценку красоты текста.
- `anything2explainer` требует разрешения автора для коммерческой эксплуатации toolkit. Remotion лицензируется отдельно.
