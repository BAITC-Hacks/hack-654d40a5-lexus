# Приоритеты реализации и дальнейшее развитие

## Поставлено в MVP

1. **25 баллов: геймификация заказчика.** Серверная формула, подтверждения по хэшу, расшифровка, ранжирование, отсутствие запрета откликов при низкой готовности.
2. **20 баллов: сквозной путь.** От идеи и вопросов до публикации, отклика, ручного решения и принятого результата.
3. **15 баллов: карточка.** Все обязательные поля, редактирование и поэтапное согласование, финальный preview.
4. **15 баллов: каталог и выбор.** Поиск, фильтры, все опубликованные карточки, несколько выбранных команд, без автоматического назначения.
5. **10 баллов: ИИ.** OpenAI strict JSON, локальный режим с явным обозначением, ≥3 вопроса, запрет придуманных фактов в промпте, обязательная проверка человеком; анализ изменений.
6. **10 баллов: техническая проверка.** Docker, healthcheck, PostgreSQL persistence, seed, README, unit/integration/browser tests.
7. **5 баллов: демонстрация.** Сценарий на 4:40, подготовленный синтетический пример, доступные роли.

Это покрытие рубрики, не обещание конкретной оценки жюри.

## Отличия продукта

- Ввод и потребление информации текстом или голосом, RU/KK/EN, доступность без платной блокировки.
- Пиксельная иллюстрация и игровые акценты без пиксельного шрифта в длинных формах.
- Согласованные версии и понятный diff, AI-рекомендации по изменениям, сохранение старого отклика и видео.
- Команды с подтверждёнными результатами, XP и отзывами после сдачи.
- Персональное объясняющее видео по конкретной версии, с pilot и ручным согласованием.
- Pro-план с честной демонстрацией платных прав; рейтинг не продаётся.
